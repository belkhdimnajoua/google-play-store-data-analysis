# Google Play Store Data Analysis 

## Project Overview
This project performs an in-depth analysis of the Android app market, comparing thousands of applications on the Google Play Store. The analysis covers data cleaning, handling missing values, deduplication, and exploratory data analysis (EDA).

## Tools Used
* Python (Pandas, NumPy)
* Data Visualization (Matplotlib, Seaborn, Plotly)

## Key Insights
* **High-Risk/High-Reward:** "GAME" and "COMMUNICATION" categories dominate downloads but have extreme competition.
* **The Sweet Spot:** Categories like "TOOLS" and "BUSINESS" offer high downloads with lower competition.
* **Quality vs. Rating:** A perfect 5.0 rating is often misleading if the app has a very low number of reviews..
